# Karelography
A path generation web app for the "Karel J. Robot" Java library. It's designed to effortlessly give you karel paths with an interactive visual interface. This tool is designed to help users understand how the Karel system works and to minimize tedious manual coding. 

## Programming Languages Used:

- Javascript
- Python
- Html
- Css
- (Maybe) Java (because it returns Java code).

Hosted on: local server (not deployed yet)
